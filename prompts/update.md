# 让 AI 增量更新档案

先阅读 [prompts/README.md](README.md)。这份提示词会要求对方先给出变更计划。对方第一次回复时不该改文件。

使用前，把 `<your-username>/<your-private-repo>` 换成你的私有仓库。你看完计划后，用这些原句授权下一步：

- `确认写入`：按计划改文件
- `可以提交`：创建提交
- `可以推送`：上传到 GitHub

只说 `确认写入` 时，默认分支还没有更新。推送成功或拉取请求合并之前，对方都必须明确说出默认分支尚未更新。

```text
—— 提示词开始 ——
请帮我把这次对话里已经确认的长期事实，更新到我的私有个人档案。先做检查并给出变更计划。在我回复“确认写入”之前，不要修改文件，不要创建提交，不要推送。

仓库：<your-username>/<your-private-repo>

开始前，任何一项不满足就停下来说明，不要改文件：
1. 当前要写入的仓库就是上面的 owner/repo。核对远程地址时，只接受 git@github.com:<your-username>/<your-private-repo>.git 或 https://github.com/<your-username>/<your-private-repo>.git。地址在 github.com 前夹有令牌时，停止，并且不要把该地址写进回复。
2. 仓库可见性为 Private。你能查看 GitHub 可见性时，请核对 visibility。你只能看见本地文件时，停下来请我明确确认“该仓库当前是 Private”。不要用“目录在本机”代替这个确认。
3. 当前仓库不是公开模板 sololeveling-a11y/ai-profile-template。不要把个人内容写回公开模板。
4. 不要为了完成更新去寻找、打印或提交密钥。不要执行会把仓库改成 Public 的操作，不要开启 GitHub Pages，不要修改协作者。

只写入同时满足这些条件的内容：
- 我在这次对话里明确确认，或档案里已有我此前的确认并且你只是在整理措辞
- 数周之后仍会影响别人如何理解我的背景、偏好、目标或项目状态
- 不含密码、令牌、支付与证件信息、精确住址、他人私人信息、未经删减的原始聊天记录
- 不是一次性琐事、调试输出、寒暄或未确认的推测

事实先暂存，再决定层级：
- 现行：我确认现在仍然成立
- 带日期的阶段：保留事件日期和时区，时区与 profile.md 一致；profile.md 还没填时区时，向我询问，不要自行假定
- 历史：已经停止。保留原日期。不要把旧日期改成今天
- 待确认：依据不足或与现有句子冲突。不要升格为现行

日期是确认或决定的日期，不是你读取文件的今天。我若在新的日期再次确认旧事项，保留旧日期为历史，另写一条新日期。

projects.md 的状态只能是已完成、进行中、未开始。不能把未开始写成进行中或已完成。缺少依据时放进待确认。
不要阅读 examples/ 来补充我的事实。那里的人物是虚构的。
不要把这次对话的原始记录整段抄进仓库。

写入前用 PRIVACY_CHECKLIST.md 的红线自查变更计划。清单正文不是我的生平。

请先用下面的结构给出变更计划，不要改文件：
1. 仓库确认：路径，以及可见性是 Private、由我另行确认，还是无法继续。
2. 建议写入：每条写明目标文件、层级、日期、时区、来源、新句子。
3. 建议改为历史：原句位置，以及从哪一天起不再当作现行。
4. 拒绝写入：只写类别和条数，例如秘密、一次性琐事、他人私人信息、推测。不要回显秘密本身。
5. 将追加到 updates.md 顶部的草稿。最新的记录在最上面。区分现行规则、历史决定、待确认。
6. 仍要我回答的问题。

可修改的文件只有 profile.md、preferences.md、goals.md、projects.md、updates.md。不要改 README.md、AGENTS.md、LICENSE、prompts/ 和 examples/，除非我在这次对话里点名要改其中某一个。

我回复“确认写入”之后，你才可以按计划修改文件，并让我看到变更内容。
只有我同时写了“可以提交”，你才创建提交。提交说明只写事项，不写秘密。
只有我同时写了“可以推送”，你才推送。不要强制推送，不要改写已推送的历史。
在推送成功或拉取请求已经合并之前，明确写出：默认分支尚未更新。
如果已经推送或合并，说明默认分支上的提交编号。无法确认编号时，写明未能确认，不要声称已经完成。
—— 提示词结束 ——
```

第一次让某个 AI 认识你，用 [start.md](start.md)。从旧记忆整理草稿，用 [migrate.md](migrate.md)。提交前对照 [PRIVACY_CHECKLIST.md](../PRIVACY_CHECKLIST.md)。
